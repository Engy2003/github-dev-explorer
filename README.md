# GitHub Profile Finder 🔍

An interactive and responsive web application that leverages the GitHub REST API to seamlessly search and render developer profiles, user statistics, and latest repositories. 

## 🚀 Live Demo
[View Live Project Here](https://engy2003.github.io/github-dev-explorer/) 
*(Note: Update this link after enabling GitHub Pages)*

## 🛠️ Built With
This project was built focusing on clean code, responsive design, and DOM manipulation without relying on heavy frameworks.
* **HTML5** (Semantic structure & Accessibility)
* **CSS3** (Flexbox, Grid, CSS Variables, Media Queries)
* **Vanilla JavaScript** (ES6+, Async/Await, Fetch API)
* **GitHub REST API** (Data fetching and dynamic rendering)

## ✨ Key Features
* **Real-time Search:** Instantly fetch user data by typing a GitHub username.
* **Quick Suggestions:** Pre-defined chips for fast testing (e.g., torvalds, gaearon).
* **Dynamic UI Rendering:** Automatically generates profile cards and repository grids based on API responses.
* **Responsive Dark Theme:** A modern, eye-friendly dark mode UI that adapts flawlessly to mobile, tablet, and desktop screens.
* **Error Handling:** Graceful fallback UI when a user is not found.

## 📂 Project Structure
- `index.html` - The main structure and meta tags for SEO.
- `style.css` - Custom styling, layout handling, and responsive breakpoints.
- `script.js` - API integration, event listeners, and DOM manipulation logic.
